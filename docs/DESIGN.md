# 李文亚知识库 · 全量视频理解与 Wiki 站点建设方案

> 版本 v1.0 · 2026-09-22 · 目标机器：AutoDL RTX PRO 6000 Blackwell 96GB / 22 vCPU / 110GB RAM

## 0. 目标（Definition of Done）

1. **全量理解**：1193 个本地 MKV（168.6 小时）逐视频产出结构化理解结果——**画面 + 台词 + 画面文字 + 音乐/音效 + 人物 + 事件**五要素齐备。
2. **纳入 B 站 13 个视频**：下载、理解、并入同一知识库（含标题/UP 主/弹幕/评论等外部语境）。
3. **知识库**：可检索（全文 + 语义 + 实体关系），以 SQLite + 向量索引 + 实体图形式落地。
4. **Wiki 站点**：仿 AMD 官网视觉语言的静态站点，内容融合本地视频理解结果与 4 个参考 wiki。
5. **可验证**：每个结论都能回溯到“哪个视频、第几秒、哪一帧”。

## 3. 五层理解流水线（L0–L7）

```text
L0 索引   ffprobe 全量元数据(时长/编码/分辨率/音轨) -> SQLite assets 表
L1 听觉   ffmpeg 抽 16k 单声道 wav
          |- faster-whisper large-v3 (VAD + 词级时间戳) -> 台词 JSONL
          |- Qwen3-8B 术语纠错(人物/理论术语表) -> 修正稿
          |- 音乐/音效: librosa 能量分段 + CLAP 零样本标签(笑声/掌声/音效/纯人声)
L2 视觉   PySceneDetect 场景切分 -> 每场景 3-5 关键帧
          |- Qwen3-VL-8B 逐帧: 人物/动作/场景/镜头/画面文字/风格
          |- RapidOCR 补充画面内文字(字幕条/PPT/网页截图)
L3 对齐   现有 SRT/TXT + ASR + OCR 三源按时间轴合并(ASR 为主, OCR 补画面)
L4 场景卡 每场景 -> {t0,t1,画面,台词,声音,人物,术语/梗,情绪} JSON
L5 视频级 一句话摘要 + 要点 + 实体关系 + 标签 + 时间线锚点
L6 知识库 SQLite(FTS5 全文) + FAISS(语义) + 实体关系图 + RAG 查询 CLI
L7 站点   Astro 静态站 + AMD 风格设计系统 + Pagefind 搜索 + 视频库/图谱页面
```

**质量守则**：任何摘要/结论必须携带 `video_id + 时间码 + 帧号` 溯源信息；ASR 与 VLM 结果分开存储，融合层只做归一化不做臆造；抽 5% 视频做交叉复核。

## 4. 知识库数据模型

- `asset` 视频资产：路径、时长、编码、所属系列、发布日期
- `segment` 场景卡：视频、起止秒、画面描述、台词、声音标签、OCR 文字
- `mention` 实体提及：segment -> 实体，带时间码
- `entity` 人物 / 理论 / 事件 / 组织 / 梗 / 地点，含别名与人格分支
- `relation` 实体关系：批判、采访、扮演、衍生……带证据 segment
- `doc` B 站视频、wiki 页面、评论文本等外部文档
- `chunk` + `embedding` RAG 检索单元，jina-v3 向量

实体消歧要点：**李文亚**本体与“清醒人格”等分支人格分开建模；孙笑川、二阶堂希罗等互动对象单列；理论词表（黑体生物理论、地球运动原理…）与梗词表（狱卒、话疗、诺委会…）随流水线迭代扩充。

## 5. Wiki 站点设计（AMD 官网风格）

- **视觉**：深色底 + 高饱和强调色、超大标题、宽幅 hero、产品式卡片网格、数据条（1193 视频 / 168 小时 / N 实体）、平滑滚动与微交互、响应式。
- **信息架构**：首页 -> 人物志 -> 理论体系 -> 事件年表 -> 梗词典 -> 视频库（检索/筛选，可查看逐场景理解结果）-> 番外与互动 -> 参考来源与版权声明。
- **技术**：Astro + Tailwind 构建纯静态；Pagefind 全文搜索；知识图谱 D3/ECharts；时间线组件；数据由知识库导出 JSON。
- **内容来源**：本地视频理解结果为主，参考 wiki 为辅（抓取清洗后**逐条标注出处**），保留原合集免责声明与中立立场说明。

## 7. 资源估算

- ASR：168.6h / 约 40 倍实时 ≈ **4–5 小时 GPU**
- VLM：约 2.9 万关键帧 x 约 1.2s ≈ **9–12 小时 GPU**
- OCR/嵌入/融合：**3–4 小时**
- 合计 **约 20 小时 GPU**；磁盘：关键帧约 6GB + 音频约 2.5GB + 索引约 2GB（剩 93GB，充裕）
